# Synthetic intake samples

`PL0005-sample-lipid-profile.pdf` is a user-provided document that explicitly identifies itself as a sample report and uses demo patient and visit fields. It is bundled only to let a person add a fictional report to the Medical Registry preview.

Adding the report stores a local copy. It does not start extraction, contact an AI provider, or add health facts. The separate source-review action explains the transfer and asks for confirmation before extraction. Every extracted suggestion remains pending until the person accepts it.

Keep this document out of seeded profile facts and production data. Use fictional data only in preview journeys.
